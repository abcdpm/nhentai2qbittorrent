使用说明

  • 推送任务：油猴脚本勾选本子后点「📤 推送到下载服务」，或用 API 提交：
curl -X POST http://127.0.0.1:8787/api/tasks \
  -H "Content-Type: application/json" \
  -H "X-API-Key: nhk_你的密钥" \
  -d '{"items":[{"gid":"123456","title":"本子标题"}]}'
  • 保存结构：下载根目录/本子名 [本子id]/页码.后缀
  • 完整性校验：每本下载完成后校验页数与文件头，缺损自动补齐重传
  • 超时重传：单次请求超时自动换节点重试（每轮把所有 CDN 节点轮询一遍）
  • 格式支持：webp / jpg / png / gif 全支持。开启“统一 WebP”后 jpg、png 转 webp；gif 转为动态 WebP，保留动画（需要 npm install sharp；未安装则保留原格式）
  • 间隔下载：“图片请求间隔”防限流，“任务间隔”控制本子之间的间隔
  • 安全：所有 API 均需 API Key，可在「API 密钥」页随时生成/吊销，公网暴露也不会被陌生人刷任务
